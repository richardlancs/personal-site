Figures in the site's content are now set in bold wherever content is
shown (`app/lib/figures.ts`, `components/city2d/Figures.tsx`). Only real
numbers go on the site: nothing below is added until you answer it, and
nothing is estimated. Where you don't know or would rather not say, leave
it out; a point without a number is fine.

Each question names the point it would sharpen (as the point reads in
`app/data/portfolio.ts` today). Answer in any form; a number with how you
know it ("from the GitHub insights", "from Vercel analytics") is ideal.
