# Shanghai Redesign, Plan A: Concept and the 2D Site — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the park site's default experience with a dark, painted, one-page 2D Shanghai whose district art follows Richmond Hill's time of day and weather.

**Architecture:** `/` becomes one server-rendered page of six "stations" (sections), each opening with a painted district band. A small client driver reads the existing Richmond Hill hook and writes the sky onto `<html>` as data attributes and CSS variables; bands show a day plate, a night plate or a cross-fade, with weather drawn over them. The park's `world3d/` code stays in the tree, unimported, for Plan B (the 3D city under `/city`), which is written after this plan's final review.

**Tech Stack:** Next.js 16.4 App Router, React 19.3, TypeScript, Tailwind 4, `next/image`, `node --test`. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-19-shanghai-cyberpunk-design.md`

## Global Constraints

- Work only in the worktree `.claude/worktrees/shanghai`, branch `shanghai`. Never touch `main`, never push.
- Every subagent runs on Opus 5.5 (`model: "opus"`). No forks.
- No new npm dependencies. No `three` import reachable from `/`.
- Content comes only from `app/data/portfolio.ts`. Invent nothing about Richard.
- One dark interface; nothing keyed on `prefers-color-scheme`; no theme switch.
- Text contrast 4.5:1 or better. Glow is never counted toward contrast and is removed under `prefers-contrast: more`.
- Neon accents (cyan, magenta, amber) are for edges, chosen states and display type of 24px or larger. Never body text.
- No text on a painting, except the hero's name on its own backing.
- `prefers-reduced-motion` and still view (`html[data-still]`, `world3d/still.ts`): no parallax, no falling rain or snow, no animated cross-fade.
- Touch targets 44×44 CSS px; no sideways scroll from 320px; body text 16px on phones; safe-area insets respected.
- Chinese characters only inside paintings. None in `app/` source in this plan.
- Plates: `app/assets/city/<district>-<day|night>.webp`, 2400px wide, at most 600 KB each as stored; served through `next/image` at about 120 KB for the 1600 width.
- 2D budget (mid-range phone, 4G): largest paint within 2.5 s, zero layout shift, first view under 600 KB, client JS for `/` no larger than today's initial JS for `/` (`docs/audit/scripts/budget.mjs`).
- Shared files are edited by the lead session only: `app/city.css`, `app/layout.tsx`, `app/page.tsx`, `app/sections/registry.ts`, `next.config.ts`, `package.json`.
- After each task: `npm run lint`, `npm test`, `npx tsc --noEmit`, all passing, then commit.
- ChatGPT is driven in Richard's Chrome. Ask him before each batch of image downloads.

## Review Focus

1. **No weather reading, or still loading.** The page shows the neutral look and the clock's daylight; nothing blank, no "undefined". (Task 3 test, Task 5 test)
2. **A plate fails or is slow to load.** The band shows its dark gradient at full height; no layout shift; content below is unaffected. (Task 5 test)
3. **JavaScript off.** Every section's content, the station list and a night plate for the hero are in the HTML. (Task 5 and Task 13 smoke tests)
4. **Old deep links.** `/projects`, `/about`, `/experience`, `/interests`, `/contact`, `/map` land on the right anchor or `/`. (Task 4 test)
5. **320px wide at 200% text, and reduced motion.** Nothing clips or scrolls sideways; nothing moves. (Task 12 test, Task 13 audit)
